# Phase 8 — i18n (PT-BR / EN) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every user-visible string comes from ARB files, the app follows the system language with PT-BR and EN support (fallback EN), dates/numbers are localised, and a guard test keeps new hardcoded strings out.

**Architecture:** `flutter_localizations` + `gen-l10n` (`AppLocalizations` generated into `.dart_tool`, imported as `package:flutter_gen/gen_l10n/app_localizations.dart`). Widgets read `context.l10n` (a tiny extension). Date helpers move from hand-rolled English lists to `intl`'s `DateFormat` with the active locale. Notification copy is built in the service from the same ARB (loaded via `AppLocalizations.delegate` for the current locale) — no UI dependency.

**Tech Stack:** Flutter 3.41, `flutter_localizations` (SDK), `intl` (pinned by flutter_localizations). No other new packages.

**Spec:** `docs/superpowers/specs/2026-08-15-consistency-v2-design.md` — fase 8. Copy source of truth: the approved design pages are in PT-BR (`home.dc.html`, `goal-sheet.dc.html`, `goal-detail.dc.html`, `calendar-month/-year.dc.html`, `settings*.dc.html`, `home-empty.dc.html`, `error.dc.html`, `widget.dc.html`) in project `b473eda8-1101-4699-a494-6390baa9a37e`; use their wording for `app_pt.arb` and the current in-code English for `app_en.arb`.

## Global Constraints

- Template ARB = `lib/l10n/app_en.arb` (with `@key` descriptions); translation = `lib/l10n/app_pt.arb`. `l10n.yaml` at the repo root, `generate: true` in pubspec.
- Locales: `en` (fallback) and `pt` (matches `pt_BR` and `pt_PT` by language). `MaterialApp.localizationsDelegates` + `supportedLocales`; **no** explicit `locale:` — follow the system.
- Placeholders use ICU: `{name}`, `{count}` with `plural` where English/Portuguese differ (`1 day` / `N days`, `1 dia` / `N dias`).
- Dates: `DateFormat` with `Localizations.localeOf(context).toLanguageTag()`. `lib/configs/date_format.dart` keeps its function names but takes a locale string; no more const English month/weekday lists.
- Percentages: `NumberFormat.percentPattern` is overkill — keep `'$n%'` but format the number with `NumberFormat.decimalPattern(locale)` only where a thousands separator could appear (streak/record counts). Not required elsewhere.
- Notifications: `ReminderService` resolves its strings through `AppLocalizations.delegate.load(locale)` using `PlatformDispatcher.instance.locale` (no BuildContext); tests pass a locale explicitly.
- A guard test (`test/no_raw_strings_test.dart`) fails when a widget file contains a bare capitalised string literal outside a whitelist (keys, `debugPrint`, `Semantics` values already localised, test helpers). Keep the whitelist tiny and explicit.
- Lints; `flutter analyze` clean; `flutter test --concurrency=1 --reporter expanded` green; `dart format lib test`; Conventional Commits; `flutter build apk --debug` must still succeed after Task 1.

`test/l10n_test.dart`:
```dart
import 'package:consistency/configs/l10n_ext.dart';
import 'package:flutter/material.dart';
import 'package:flutter_gen/gen_l10n/app_localizations.dart';
import 'package:flutter_test/flutter_test.dart';

void main() {
  testWidgets('English and Portuguese resolve the same keys', (tester) async {
    for (final (locale, greeting, record) in [
      (const Locale('en'), 'Hi, Alvaro', 'record 12 days'),
      (const Locale('pt'), 'Olá, Alvaro', 'recorde 12 dias'),
    ]) {
      late AppLocalizations l;
      await tester.pumpWidget(MaterialApp(
        locale: locale,
        localizationsDelegates: AppLocalizations.localizationsDelegates,
        supportedLocales: AppLocalizations.supportedLocales,
        home: Builder(builder: (context) {
          l = context.l10n;
          return const SizedBox.shrink();
        }),
      ));
      expect(l.greeting('Alvaro'), greeting);
      expect(l.recordDays(12).toLowerCase(), record);
      expect(l.streakDays(1), isNot(contains('days')));
    }
  });

  testWidgets('an unsupported locale falls back to English', (tester) async {
    late AppLocalizations l;
    await tester.pumpWidget(MaterialApp(
      locale: const Locale('fr'),
      localizationsDelegates: AppLocalizations.localizationsDelegates,
      supportedLocales: AppLocalizations.supportedLocales,
      home: Builder(builder: (context) { l = context.l10n; return const SizedBox.shrink(); }),
    ));
    expect(l.newGoal, 'New goal');
  });
}
```
